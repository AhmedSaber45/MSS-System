- When clicking Add New Model, open the Add Model modal above the currently open Add Device modal.
- The Add Model modal must appear as a secondary overlay/modal without closing, resetting, or replacing the Add Device modal.
- Preserve all data already entered in Add Device, including:
  - Selected warehouse/branch.
  - Selected model, if any.
  - Device information.
  - Serial number.
  - Price and cost fields.
  - Any other entered values or selections.
- Follow the same modal layering and behavior already implemented in the Accessories module for creating a model while adding a product.
- Reuse the existing implementation or modal pattern from Accessories where applicable, but adapt it properly to Compu MSS architecture and data flow.
- After successfully creating the new model:
  - Close only the Add Model modal.
  - Keep the Add Device modal open.
  - Refresh the model selection list immediately.
  - Automatically select the newly created model in the Add Device modal.
  - Allow the user to continue completing and saving the device without re-entering any previously typed data.

### Important
Do not navigate away from the Add Device modal.

Do not reload the page.

Do not reset the parent modal state.

Do not create duplicate model records.

Ensure the new model is saved using the existing Compu MSS model creation logic and appears correctly in all relevant model lists.
