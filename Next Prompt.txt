# Add Configurable Export Storage Location and Automatic File Organization

## Objective

Add a new setting that allows the user to choose a custom destination folder for all exported and generated files from both modules:

- Accessories
- Compu MSS (MSS)

## 1. Storage Location Setting

Add a new setting under the existing application Settings page:

**Setting name:** Export Files Storage Location

- Allow the user to select a destination folder using the native Windows folder picker.
- Display the currently selected path.
- Allow changing the destination at any time.
- Persist the selected path across application restarts.
- Use the existing Tauri v2 architecture and secure filesystem APIs.

## 2. Automatic Root Folder Creation

Inside the selected destination, create a root folder named:

`MSS System Files`

Create it automatically during the first export operation, not immediately when the user selects the destination.

- Reuse existing folders for subsequent exports.
- Do not create duplicate folders.

- Never silently lose an exported file.
- Avoid unintentionally overwriting existing files.
- Changing the destination must affect future exports without moving or deleting previously exported files.
- Ensure multi-file and multi-page exports save all generated files in the correct folder.
